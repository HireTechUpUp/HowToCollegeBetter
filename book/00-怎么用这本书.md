# 0. 怎么用这本书

## 这本书是什么

这是写给中国大陆本科生的高性价比备选单，目标是用尽量少的钱、时间和精力，在大学四年换回更多身体、能力、选择权和工作机会。它是一张备选单，不是任务清单，眼下挑一两条做就算数，剩下的等遇到问题再回来查。内容可能过时，也可能有错，涉及学校、考试、医保、就业和法律的事情，一律以学校和官方最新通知为准。发现错误或过时链接，欢迎在项目仓库提 issue。

## 怎么读一条建议

每条建议都拆成六栏。先读「一句话」，确认它是不是你现在的问题，再看「怎么做」决定下一步；「花多少」让你估算钱、时间和毅力，「证据」说明依据有多硬，「来源」让你回到原文，「注意」提醒它什么时候不适用。

| 栏目 | 读法 |
| --- | --- |
| 一句话 | 把建议放进宿舍、课表、考试周或求职场景，说明为什么值得考虑 |
| 怎么做 | 给出 1–3 个可以执行的动作，通常会写时间、地点或数量 |
| 花多少 | 写钱、时间和毅力，三者都可能有成本 |
| 证据 | 标出依据等级，并用半句话说明证据支持到哪一步 |
| 来源 | 链到研究、官方文件或观点的原始页面 |
| 注意 | 说明适用边界、学校差异和常见误区 |

证据等级按本书的规则理解。

- **A**　荟萃分析或系统综述，能把多项研究合在一起看，结论通常更稳定，但仍要看研究对象和场景。
- **B**　单项研究或权威专业指南，有依据可查，外推到你的学校或个人时要留余地。
- **C**　官方文件、政策、通知和风险提示，适合确认规则、程序和法律边界，不等于研究证明了某个效果。
- **观点**　名人理念、行业经验或编辑判断，能帮助取舍和行动，但不冒充医学、学习或就业证据。

证据等级回答的是「依据有多硬」，不是「这件事一定适合你」，也不是收益大小。学校规则、岗位要求和法律政策有变化时，回到最新官方页面。

### 用一条现有建议示范

下面复述第 5 章的「转专业前把培养方案、补修学分和毕业时间算一遍」，不新增建议。

| 栏目 | 这一条里写的内容 |
| --- | --- |
| 一句话 | 真正的代价不是申请表，而是少修的必修课、补修课和可能延后的毕业时间。 |
| 怎么做 | 下载原专业和目标专业培养方案，列出已修、可认定、需补修三栏，把每学期课表排一遍，再带着差额学分问教务处。 |
| 花多少 | 不花钱；半天到一天；需要接受结果可能是不转。 |
| 证据 | C。教育部规定学生可按学校办法申请转专业，具体标准和程序由学校制定。 |
| 来源 | [教育部《普通高等学校学生管理规定》](https://www.moe.gov.cn/srcsite/A02/s5911/moe_621/201702/t20170216_296385.html) |
| 注意 | 申请窗口、名额和课程认定都以本校教务处书面通知为准。 |

# 第 8 章　求职主线

<img src="../assets/brand/UP求职-logo.png" alt="UP求职" height="32">

这一章解决三件事：先选方向，再把四年里的课程、项目和实习变成能核验的证据，最后把投递、笔面、签约和落空后的下一步排好。你不需要大一就决定一辈子做什么，但要尽早知道自己在比较什么、什么时候该换。求职地图把六个方向、十二条路线和九个阶段放在一张图里，本章补上每天能做的动作。芒格说，想得到什么，先努力让自己配得上它；放到求职里，就是先做出作品、技能和守约记录，再等机会来检验（[2007 年 USC 演讲逐字稿](https://finmasters.com/wp-content/uploads/2022/02/2007-USC-Law-School-Commencement-Address-by-Charlie-Munger-Transcript.pdf)）。巴菲特讲能力圈，选岗时先承认自己会什么、不会什么，再决定深入还是补课（[1996 年股东信](https://www.berkshirehathaway.com/letters/1996.html)）。

## 四年速查表

| 阶段 | 这一阶段求职上最该做的事 |
|---|---|
| 大一全年 | 看懂六方向，保存课程作业、社团和志愿活动中的个人贡献 |
| 大二全年 | 选两条主线，做一个能展示的课程项目或研究成果 |
| 大三上 · 9–1 月 | 按目标路线核对资格和材料，准备实习、考研或留学考试 |
| 大三下 · 2–6 月 | 集中补技能缺口，投暑期实习或准备升学申请材料 |
| 大三暑期 · 7–8 月 | 实习或做项目，留下成果、反馈和可核验记录 |
| 大四秋 · 9–10 月 | 按毕业届别投秋招，完成网申、测评和首轮面试 |
| 大四冬 · 11–1 月 | 跟进笔面、国考或升学考试，复盘每次失分 |
| 大四春 · 2–4 月 | 参加春招、补录或复试，重新排序机会 |
| 毕业衔接 · 5 月起 | 核对签约、档案、户口和入职材料，安排下一站 |

完整月份窗口、路线细节和当年公告见[大学生求职地图](https://www.upcv.tech/qiuzhiditu?channel=github)。地图的六方向是考公考编、国企央企、民营企业、外资企业、国内升学、海外／境外留学，不含创业和灵活就业；资格和截止时间始终以当年正式公告为准。

## 1. 定方向

### 先从六个方向里选两条主线，别把自己困在一个答案里
- 一句话：宿舍里都在聊考研或进大厂时，比较岗位内容、准备成本和生活地点，别跟着群消息投票。
- 怎么做：本周写六方向比较表，列已有作品、条件缺口和决定时间；选一条主线、一条备选，找辅导员聊一次。
- 花多少：钱 0 元 / 时间 2 小时 / 毅力 按时更新
- 证据：观点，六方向和九阶段来自求职地图，表格是编辑建议，不代表录用概率。
- 来源：[求职地图](https://www.upcv.tech/qiuzhiditu?channel=github)
- 注意：创业、灵活就业可以另行规划，不要悄悄算进六方向的比较结果。

### 用课程和作品检查能力圈，三个月后再决定是否换线
- 一句话：如果你对某方向只有“听起来体面”的印象，先用课程、小项目或信息访谈换成具体认识。
- 怎么做：给每条主线找一个真实岗位，连续 4 周各投入 2 小时；记录顺手、卡住和愿意继续的部分，期末复盘。
- 花多少：钱 0–100 元 / 时间 每周 2 小时 / 毅力 允许自己改答案
- 证据：观点，能力圈是巴菲特的投资理念迁移，不能替代岗位资格或就业统计。
- 来源：[1996 年伯克希尔股东信](https://www.berkshirehathaway.com/letters/1996.html)
- 注意：一次作业不等于职业结论，身体状况、家庭安排和现实机会也要一起看。

### 出现明确新信息时换主线，别因为沉没成本硬撑
- 一句话：大三下发现考试资格不符，或实习让你确认不想做这类工作，及时换线比刷无效材料省时间。
- 怎么做：每月更新“资格、成本、反馈、退路”四格表；硬条件不成立，就在两周内向老师核对替代路线。
- 花多少：钱 0 元 / 时间 每月 1 小时 / 毅力 接受重排
- 证据：观点，地图允许路线间切换，具体资格仍需回到单位、学校和项目公告核对。
- 来源：[求职地图阶段说明](https://www.upcv.tech/qiuzhiditu?channel=github)
- 注意：不要只因一次 HR 已读不回就换方向，先看是否是岗位批次、材料或时间窗口问题。

## 2. 攒证据

### 从大一开始建一份“我做了什么”证据夹
- 一句话：课程报告、实验记录和社团活动散在电脑和宿舍群里，秋招只剩“负责过”，招聘者看不出贡献。
- 怎么做：建“课程／项目／实习／竞赛”四个文件夹，保存成果、个人贡献和指导者联系方式；每学期整理一次。
- 花多少：钱 0–20 元 / 时间 每学期 2 小时 / 毅力 持续归档
- 证据：观点，求职地图把动作、材料、结果分开列出，本条是把它变成个人记录的编辑建议。
- 来源：[求职地图内容与使用口径](https://www.upcv.tech/qiuzhiditu?channel=github)
- 注意：涉及同学、客户或实验数据时先去标识化，未经允许不要把内部文件放进公开作品集。

### 每学期留下一个能展示的成果，数量少一点也没关系
- 一句话：比起在秋招群里写十个“参与过”，一份能打开、讲清过程和结果的作品更能支撑面试追问。
- 怎么做：每学期选一个成果，补齐目标、动作、结果和复盘；请老师、导师或队友确认事实。
- 花多少：钱 0–200 元 / 时间 每学期 6–10 小时（建议值） / 毅力 接受反复修改
- 证据：B，关于实习与就业能力的系统综述把技能增长、专业网络和职业身份列为中介机制，不能推出任何个人必然录用。
- 来源：[实习与就业能力系统综述](https://eric.ed.gov/?ff1=eduHigher+Education&id=EJ1510262&q=internship)
- 注意：该系统综述刊于一般期刊，只作背景证据；没有公开链接的成果也可以保留为面试材料，但不要伪造数据或把团队成果全写成个人成果。

### 每学期只留一个主目标和一个备选目标
- 一句话：课表、社团和秋招群同时推来十件事时，先定本学期影响下一步的那一件，别每项都做半截。
- 怎么做：开学首周写主目标的可交付结果和截止日，再写一个备选；每周日删掉一项不能服务这两个目标的活动。
- 花多少：钱 0 元 / 时间 每周 15 分钟 / 毅力 学会拒绝
- 证据：观点，属于时间分配和机会成本的编辑建议，没有把它说成就业研究结论。
- 来源：[求职地图九阶段](https://www.upcv.tech/qiuzhiditu?channel=github)
- 注意：考试、健康和学校硬性要求优先于求职计划，主目标可以按新信息调整。

## 3. 简历

### 先做一份一页母版，再为岗位改三处
- 一句话：招聘者在手机上扫简历时，课程、项目和联系方式要一眼找到；一页是本科生常用建议值。
- 怎么做：按相关性排教育、项目、实习、技能；投递前改岗位名称、项目顺序和两处真实关键词，另存版本。
- 花多少：钱 0 元 / 时间 每份 20–30 分钟（建议值） / 毅力 逐份核对
- 证据：B，多个高校职业中心建议本科生简历控制在一页，政府岗位或研究申请可能需要更长版本。
- 来源：[Boston College 简历指南](https://www.bc.edu/content/bc-web/offices/studentaffairs/sites/careers/prepare/resume.html)、[伯克利简历指南](https://www.career.berkeley.edu/prepare-for-success/resumes/)
- 注意：关键词只能来自真实经历，别用白字堆词，也别把同一份简历无差别投给六个方向。

> 免费做法是先用岗位公告自己改一页母版，再逐份核对事实。想有人陪你一起做，可以了解 [UP求职（原 UP简历）](https://www.upcv.tech/?channel=github)，导师可结合你的背景和目标梳理经历、人工精修简历，具体服务内容以服务合同为准。

### 让 AI 出初稿，让自己对每个字负责
- 一句话：AI 可以整理零散经历，宿舍里容易漏掉的是句子漂亮，却说不清自己做了什么。
- 怎么做：只提供去标识化经历和岗位描述；逐项补回真实数字、时间和工具；提交前朗读并留好原始材料。
- 花多少：钱按工具规则，先用免费功能 / 时间 30 分钟 / 毅力 人工核实
- 证据：观点，UP求职现有页面把 AI 定位为“写简历、筛选合适岗位、自动填写校招网申、跟进投递进度并完成模拟面试”的工具，不能替你证明经历。
- 来源：[UP求职官网现有文案](https://www.upcv.tech/?channel=github)、[UP求职简历模板页](https://www.upcv.tech/jianlimoban?channel=github)
- 注意：不上传身份证号、联系方式以外的敏感信息、未公开项目或他人简历；学校和单位有 AI 使用限制时按其规则。

## 4. 实习

### 投实习前先问清工作、指导、成果和收费
- 一句话：看到“名企实习”先确认每天做什么、谁带你、成果归谁、是否收费。
- 怎么做：面试前写下岗位、地点、时间、指导人和费用五个问题；不愿书面说明或要求先交钱就停止并留证。
- 花多少：钱 0 元 / 时间 30 分钟 / 毅力 敢于退出
- 证据：C，人社部风险提示明确列出虚假招聘、保录内推、违规收费等求职陷阱。
- 来源：[人社部等部门风险提示](https://www.mohrss.gov.cn/wap/xw/rsxw/202605/t20260525_576845.html)
- 注意：学校统一实习可能另有流程，仍要核对学校实习管理办法和单位书面安排。

### 实习结束当天写一页成果复盘
- 一句话：没有记录的实习，简历里往往只剩“协助”；记下任务、动作、结果和反馈，面试才有细节。
- 怎么做：每周五记三行日志；离开前整理成果，标注可公开范围、贡献、工具和主管反馈，并确认表述。
- 花多少：钱 0 元 / 时间 每周 15 分钟 / 毅力 诚实区分团队贡献
- 证据：B，实习系统综述支持技能增长、网络和职业身份与就业能力相关，但不证明每份实习都有同样收益。
- 来源：[实习与就业能力系统综述](https://eric.ed.gov/?ff1=eduHigher+Education&id=EJ1510262&q=internship)
- 注意：该系统综述刊于一般期刊，只作背景证据；保密项目只写问题类型和你的方法，不能复制客户数据、内部截图或代码。

### 先核对官方公告和公司资质，再去实习
- 一句话：秋招群里的“高薪实习”可能没有真实岗位，先到企业官网、学校就业网或正规平台交叉核对。
- 怎么做：保存公告链接和时间；用官网联系方式确认岗位；把地点、联系人和费用要求发给辅导员留痕。
- 花多少：钱 0 元 / 时间 20 分钟 / 毅力 多查一步
- 证据：C，政府风险提示建议通过合法正规渠道了解招聘信息，警惕先收费和虚假承诺。
- 来源：[深圳人社求职陷阱提醒](https://www.sz.gov.cn/ztfw/jylyfwzt/wyk_184808/content/mpost_10632195.html)
- 注意：正规公司也可能委托招聘机构，关键是核对授权、岗位和收费，而不是只看公司名气。

## 5. 笔试和面试

### 按公告拆笔试科目，每周只练能反馈的题
- 一句话：把所有题库下载到电脑不会让你更接近目标，先按单位公告确认科目、题型和时间。
- 怎么做：建“科目—薄弱点—错因”表；每周 3 次 45 分钟计时练习，周末做一次整套复盘。
- 花多少：钱 0–200 元 / 时间 每周 3–5 小时（建议值） / 毅力 记录错因
- 证据：观点，具体科目和日程必须以当年公告为准，求职地图只提供阶段规划。
- 来源：[大学生求职地图阶段与公告说明](https://www.upcv.tech/qiuzhiditu?channel=github)
- 注意：考研、国考、事业单位和企业测评不是同一套考试，别把一个题库当通用答案。

### 用同一套结构练三次面试，再根据录音改
- 一句话：面试前在宿舍默念答案不等于会回答，把自我介绍、项目追问和失败复盘说给真实的人听。
- 怎么做：按“情境—任务—行动—结果—复盘”写 6 个故事；找同学或老师做 3 次模拟，录音后各改一处。
- 花多少：钱 0 元 / 时间 3 次×40 分钟 / 毅力 接受具体批评
- 证据：观点。高校职业中心的 STAR 指南建议从岗位要求出发准备具体经历，并通过录音或模拟练习改进表达；这支持练习方法，不推出录用结果。
- 来源：[USC Career Center 面试准备与 STAR 指南](https://careers.usc.edu/channels/prepare-for-an-interview/)
- 注意：不同路线的面试重点不同，公职、国企、民企、外企和升学复试要回看各自公告与岗位要求。

> 免费做法是先用岗位 JD 自己写六个故事，找同学录音互问，再按追问补证据。想有人陪你一起做，可以了解 [UP求职（原 UP简历）](https://www.upcv.tech/?channel=github)，导师可定面试策略、做模拟面试并陪你复盘，具体服务内容以服务合同为准。

### 把每次投递和已读不回写进一张表
- 一句话：HR 已读不回很常见，靠情绪猜原因只会耗掉晚上；记录状态，才能分辨资格、材料或批次问题。
- 怎么做：表格记公司、岗位、链接、投递日、状态和跟进日；超过公告时间只礼貌跟进一次，之后转投下一项。
- 花多少：钱 0 元 / 时间 每次 3 分钟 / 毅力 接受没有回信
- 证据：A，求职搜索元分析发现投入程度与面试、offer 和就业状态存在相关关系，相关不等于因果。
- 来源：[求职搜索与就业成功定量综述](https://dare.uva.nl/id/5756b864-bdbd-403d-bef0-caa2dee3a6e4)
- 注意：同一自然年秋招和春招可能面对不同届别，别把别人的截止日当成自己的。

## 6. 谈 offer 和签约

### 口头 offer 到手后，把四项条件写下来再比较
- 一句话：群里说“月薪过万”不够用，影响生活的是薪资结构、工作地点、试用期和社保公积金。
- 怎么做：让 HR 书面确认薪资、发薪日、地点、试用期、社保公积金和报到时间；用一张表比较。
- 花多少：钱 0 元 / 时间 1 小时 / 毅力 逐项追问
- 证据：C，劳动合同法列出劳动报酬、工作地点、劳动保护和社会保险等合同事项。
- 来源：[中华人民共和国劳动合同法（国家法律法规数据库）](https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf74d7106b3)
- 注意：奖金、股票、补贴和试用期工资的口径要分开写，不能只比较一个总数。

### 三方协议和劳动合同分开看，签字前逐条读完
- 一句话：三方协议是毕业生就业协议，不等于劳动合同；签字前看违约、报到、档案和户口安排，拿不准就问学校。
- 怎么做：协议拍照存档，圈出违约金、主体、报到时间和档案去向；再对照劳动合同法看工资、地点和社保。
- 花多少：钱 0 元 / 时间 45 分钟 / 毅力 不在空白处签字
- 证据：C，教育部大学生在线说明三方协议与劳动合同性质不同；劳动合同细节可继续看 [HowToWorkBetter](https://nicecao.github.io/HowToWorkBetter/)。
- 来源：[中国大学生在线毕业手续说明](https://dxs.moe.gov.cn/zx/a/xzbx_sy/250527/2007503.shtml)、[HowToWorkBetter](https://nicecao.github.io/HowToWorkBetter/)
- 注意：不同学校对网签、解约和档案流程不同，学校系统和当年通知优先。

> 免费做法是先下载协议、逐项标注疑问，再向学校就业办确认。想有人陪你一起做，可以了解 [UP求职（原 UP简历）](https://www.upcv.tech/?channel=github)，导师可帮你权衡 Offer 并准备谈薪，具体服务内容以服务合同为准。

## 7. 防骗

### 出现招转培、培训贷或付费内推，先停止付款
- 一句话：对方先夸你“面试即入职”，再说能力不够要贷款培训，这是风险信号。
- 怎么做：不签贷款、不转账；保存招聘页面、聊天和合同；把公司和中介发给学校就业办，向人社或公安咨询。
- 花多少：钱 0 元 / 时间 30 分钟核验 / 毅力 顶住催促
- 证据：C，人社部等五部门风险提示明确提醒招转培、培训贷、保录和违规收费风险。
- 来源：[人社部等五部门风险提示](https://www.mohrss.gov.cn/wap/xw/rsxw/202605/t20260515_576264.html)
- 注意：正规职业培训也可能收费，关键是培训与招聘是否混同、是否承诺就业结果、是否要求贷款。

### 不交押金、不交服装费，也不把证件交给单位
- 一句话：正常招聘不应以先交钱作为获得工作机会的前提，身份证和毕业证也不该被公司扣留。
- 怎么做：遇到押金、报名费、转正费先暂停；只给写明用途的复印件；原件自己保管，异常就留证求助。
- 花多少：钱 0 元 / 时间 10 分钟查条款 / 毅力 坚持说不
- 证据：C，人社部提示用人单位不得扣押劳动者居民身份证和其他证件，官方风险提示也列出多种违规收费。
- 来源：[人社部证件扣押问答](https://www.mohrss.gov.cn/SYrlzyhshbzb/ztzl/rslyyhyshj/zcwd/202407/t20240723_522708.html)、[人社部风险提示](https://www.mohrss.gov.cn/wap/xw/rsxw/202605/t20260525_576845.html)
- 注意：学校办理学籍、实习或报到手续可能需要核验原件，但应说明用途和归还时间。

### 不借银行卡、手机号和支付账户给“兼职”收款
- 一句话：宿舍群里“借卡一天赚几百”的兼职，可能把你的账户变成诈骗通道。
- 怎么做：拒绝出借或代收款；已提供信息就联系银行和平台处理；保存账号、聊天和转账记录并咨询警方。
- 花多少：钱 0 元 / 时间 1 小时处理 / 毅力 不贪快钱
- 证据：C，中国人民银行要求银行和支付机构告知出租、出借、出售、购买账户的法律责任和惩戒措施，并对相关账户采取惩戒措施。
- 来源：[中国人民银行关于进一步加强支付结算管理、防范电信网络新型违法犯罪有关事项的通知](https://www.pbc.gov.cn/zhengwugongkai/4081330/4406346/4693545/2025112114420396601/2019032810261349347.pdf)
- 注意：实习报销和工资应走正规单位流程，不能因为对方说“只是帮忙过账”就例外。

## 8. 秋招落空了怎么办

### 秋招没结果时，保留升学、实习和下一批招聘三条信息流
- 一句话：大四秋刷到深夜仍没有 offer，不要当天退学或借钱，先保住还能推进的三条路。
- 怎么做：本周各列 3 个选项；每天安排春招或补录、实习或项目、升学信息各一段；两周后按反馈重排。
- 花多少：钱 0–200 元 / 时间 每周 8–10 小时（建议值） / 毅力 承受不确定
- 证据：观点，求职地图把大四冬、大四春和毕业衔接分开，说明秋招不是唯一窗口。
- 来源：[求职地图九阶段](https://www.upcv.tech/qiuzhiditu?channel=github)
- 注意：升学报名、春招和补录有各自资格与截止日，必须看当年公告，不能把计划表当报名入口。

### 把“没回信”拆成资格、材料和面试三个问题
- 一句话：连续被拒不等于你不适合工作，先看卡在哪一步，再改影响结果的一处。
- 怎么做：把最近 10 次申请按无回应、笔试、面试、offer 分类；请老师或同学抽查 3 份材料，下一周只改一个短板。
- 花多少：钱 0 元 / 时间 2 小时 / 毅力 面对具体反馈
- 证据：A，求职搜索综述支持对求职活动和质量做区分，不能用拒信数量直接推断个人能力。
- 来源：[求职搜索与就业成功定量综述](https://carlsonschool.umn.edu/sites/carlsonschool.umn.edu/files/2021-06/VanHooftKammeyerMuellerWanbergKanferBasbug_JAP%202021.pdf)
- 注意：很多单位不会给详细反馈，复盘只能形成假设，不能把猜测写成 HR 的真实评价。

### 毕业衔接先办手续，再继续找工作
- 一句话：没有 offer 也要先问清档案、户口、医保和求职登记，别让手续卡住下一份机会。
- 怎么做：毕业前向就业办要书面清单，确认档案去向、签约状态、户口和医保；保存扫描件和办理进度。
- 花多少：钱 0 元 / 时间 半天 / 毅力 按清单办完
- 证据：C，教育部面向大学生的毕业手续说明把就业协议、档案等列为毕业阶段需要处理的事项。
- 来源：[中国大学生在线毕业手续说明](https://dxs.moe.gov.cn/zx/a/xzbx_sy/250527/2007503.shtml)
- 注意：学校、户籍地和目标单位的办理规则可能不同，具体期限以学校和当地公共就业服务机构通知为准。

# 高性价比大学生活指南

讲大学四年怎么少走弯路：第一个月先搞懂哪些规则，怎么睡够、吃好、不把身体搞坏，<br>
怎么学得省力，钱怎么花、哪些坑别踩，室友、老师、恋爱怎么处，<br>
求职怎么从大一开始准备，毕业手续怎么一次办对，遇到挂科、落榜、失恋怎么缓过来。

每条建议写明花掉什么、换回什么、证据有多硬，来源尽量只引研究原文和官方文件。

**不用全做：这是一份备选单，不是任务清单。挑走一两条就算数。**

## 一条建议怎么读

```
### 一句可以照做的话
- 一句话：为什么值得做
- 怎么做：1–3 个具体动作
- 花多少：钱 / 时间 / 毅力
- 证据：A / B / C / 观点
- 来源：可点开的链接
- 注意：什么时候不适用
```

| 等级 | 意思 |
|---|---|
| **A** | 荟萃分析或系统综述：很多项研究合起来算的结论 |
| **B** | 单项研究，或 WHO 这类权威专业机构的指南 |
| **C** | 法律、政策、官方通知和风险提示 |
| **观点** | 巴菲特、芒格、稻盛和夫等人的理念，以及经验和编辑判断。只当思考工具，不冒充证据 |
